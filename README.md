# Aprendendo-Lógica-de-Programação

## Sobre o projeto

Este repositório reúne as minhas soluções dos desafios propostos no curso. O objetivo foi praticar os fundamentos da lógica de programação e criar uma base sólida para seguir na área de desenvolvimento web.

## O que foi praticado

- `console.log`, `alert` e `prompt`
- Variáveis e template strings
- Condicionais: `if`, `else if` e `else`
- Operadores ternários
- Loops com `while`
- Números aleatórios com `Math.random`

## Como executar

1. Abra a pasta do projeto no **VS Code**.
2. Inicie com a extensão **Live Server**.
3. Abra o console do navegador (`F12` > **Console**) para ver os resultados.
